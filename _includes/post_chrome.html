{%- comment -%} Language + navigation bar for standalone essay posts. These posts use `layout: null` and are complete HTML documents with their own styling, so this include ships its own scoped styles rather than relying on the site stylesheet. Drop it immediately after in such a post. Front matter the post should set: lang — "en" or "de" (defaults to site.default_lang) translation_key — shared identifier linking the two language versions {%- endcomment -%} {%- assign lang = page.lang | default: site.default_lang -%} {%- assign t = site.data.i18n[lang] -%} {%- if lang == 'de' -%} {%- assign other = 'en' -%} {%- assign home_url = '/de/' -%} {%- else -%} {%- assign other = 'de' -%} {%- assign home_url = '/' -%} {%- endif -%} {%- assign target = page.translation_url -%} {%- if target == nil and page.translation_key -%} {%- for post in site.posts -%} {%- assign post_lang = post.lang | default: site.default_lang -%} {%- if post.translation_key == page.translation_key and post_lang == other -%} {%- assign target = post.url -%} {%- break -%} {%- endif -%} {%- endfor -%} {%- endif -%} {%- assign other_name = site.data.i18n[other].lang_name -%}
